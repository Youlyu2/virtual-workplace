# 验证范围

此公开源码快照对应0.9.3。以下是该快照的检查范围摘要，已移除开发期间的个人机器信息、真实会话标识和工作内容。

## 已执行的检查

- 0.9.3 后台读取器的隔离内存回归、绘图连续帧检查与内存守卫验证；测试范围和复现方法见[内存说明](MEMORY.md)。

- Apple Silicon、macOS26环境的应用、独立及内嵌屏保构建，plist和本地ad-hoc签名检查。
- 人物状态、手动动作、键鼠输入动画、四方向步态、像素猫和减少动态效果。
- 待办模型、原子持久化、容量与字数限制、交办撤销、稳定访客身份、布局和透明边缘。
- 待办面板的复制失败处理、保存失败保留、普通回车换行、中文组词保护、快捷键提交及Esc草稿恢复。
- 全局快捷键注册、冲突、按住去重、事件派发与释放；实体键盘跨应用唤起和输入框聚焦经现场确认。
- 天气阈值、基础天气恢复、雷雨相位与裁切、房间窗玻璃遮罩和跨显示器远景连续性。
- 真正的屏保bundle在隔离诊断宿主中读取另一个进程的状态更新，保留损坏文件前的有效状态，并处理离线心跳；隐藏时不启动持续动画计时器。
- 实际系统全屏预览中，主屏房间与另一屏户外的路由及户外访客显示经现场确认。曾观察到系统宿主缓存旧版本，刷新宿主后预览使用了更新后的代码。

## 验证边界

自动化或离屏诊断不等于系统全场景验收。当前记录不覆盖所有Mac型号、Intel处理器、较早macOS版本、全部显示器布局、物理插拔和长期锁屏/睡眠唤醒循环。全屏预览通过不能扩大为锁屏后的长期生命周期通过。

Codex内部IPC会随桌面版本变化；本快照中的实时接入验证不能保证未来桌面版本仍兼容。未安装Codex时可使用手动状态、待办和模拟演示。

## 在自己的Mac上复验

在仓库根目录运行对应的 `scripts/test-*.sh`。屏保独立宿主检查：

```sh
./scripts/build.sh
./scripts/diagnose-saver.sh --headless-roundtrip
```

该诊断使用隔离测试状态，不能替代系统选择器、真实全屏、锁屏和多显示器检查。手动检查步骤见[屏保说明](SCREENSAVER.md)，数据范围见[隐私与本地数据](PRIVACY.md)。

提交问题时请说明macOS版本、芯片类型、显示器数量、应用/屏保版本和复现步骤，使用模拟内容截图。不要上传个人 `state.json`、会话日志或未脱敏的便签。
