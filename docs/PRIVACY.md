# 隐私与本地数据

本项目没有账号系统、云同步或照片上传功能。场景、待办与配置在本机处理。天气由手动设置、本机时间和待办等待时长产生，不请求定位或联网天气。

## Codex 实时模式读取什么

应用以只读方式读取当前用户的Codex会话索引、桌面元数据及本地事件日志，并连接本机桌面的内部IPC。用于显示的内容包括会话标题、主机来源、任务状态、当前工具名、最近一条可见助手进展和可用的时间信息。

详情提取不将工具参数、工具输出、推理正文或代理间消息写入共享场景快照；应用不读取登录凭据，也不修改Codex配置、执行任务或回答审批。内部订阅可能收到会话快照，该协议属于实验性兼容层，详细限制见[Codex接入说明](CODEX.md)。

远端状态来自Codex桌面已有连接。应用不自行读取SSH凭据、连接开发机或安装远端代理。

## 本机保存什么

数据位于当前用户的 `~/Library/Application Support/VirtualWorkplace/`：

| 文件或目录 | 内容 |
| --- | --- |
| `pending-notes.json` | 已保存的便签原文、稳定标识、创建时间和访客槽位 |
| `world-settings.json` | 天气、昼夜及每块显示器的背景选择 |
| `state.json` | 主应用发布给窗口、桌面和屏保的场景快照 |
| `Backups/` | 更新应用或屏保前保留的旧安装包 |

这些文件是本机明文文件，不是加密保险箱。会话标题、可见进展与便签摘要会出现在桌面和屏保画面中；使用者应按所处环境决定是否展示。分享问题报告时请用模拟数据，并检查截图、日志和快照是否含私人内容。

待办输入草稿只保留在本次应用进程中。Esc收起面板不会清空草稿，完全退出应用不会把未保存草稿当成已保存便签。

## 复制、交办和删除

「复制任务」只把你选中的便签放到本机剪贴板。「复制并打开Codex」同时尝试打开已安装的Codex；内容由你粘贴并发送，本应用不会自动提交任务。标记「已交办」会移除便签及访客，本次运行中可撤销最近一次交办。

卸载脚本保留数据和备份。需要清空个人数据时，先退出应用，再自行管理上述用户目录；请保留仍需使用的便签和备份。

## 快捷键和屏保

全局快捷键使用macOS特定组合键注册接口，不记录通用键盘输入。场景中的键盘、鼠标和人物动作是动画，不读取或模拟真实键鼠操作。

屏保只读取共享快照，不独立订阅Codex或创建任务。安装器不修改锁屏密码、睡眠或系统保活设置。源码构建及诊断可参阅[屏保说明](SCREENSAVER.md)。
