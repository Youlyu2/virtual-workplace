# 功能说明

本说明对应源码版本0.9.4。安装和构建见[README](../README.md)。

## 人物与任务屏幕

人物以背影为主，在坐着打工、站着打工和躺床睡觉之间切换。工作时会交替敲键，右手以较低频率随机操作鼠标。自动模式下持续工作一段时间后，会沿上下左右四个方向散步，再回到工位；转弯会停步换朝向。

手动动作包括喝咖啡、伸懒腰、挥手和逗猫。像素猫独立呼吸、眨眼、动耳、坐起、走动和互动。系统启用减少动态效果时，减少循环动作和过渡。

场景常驻三块基础显示器，空闲屏显示概览和待处理信息；第四至第六个会话展开上排屏幕。最多同时呈现六个会话，超出时优先显示工作中、等待确认和出错等需要关注的会话。真实来源未提供进度、下一步或时长时，相关信息留空。

实时模式只读，不提供修改真实任务的按钮。选择模拟模式后，可以增加或关闭模拟会话，并切换工作中、等待确认、完成和出错。任务完成不会立即移除屏幕，关闭会话后才回收对应屏幕。演示覆盖多屏、状态变化、站姿和摸鱼；手动修改会停止演示。

## 门外访客

每条便签对应一位固定造型的访客，最多八位。角色具有不同发型、衣服和体型，按持久化槽位保留身份，移除其他便签不会换人。访客在近景小路与草地上四方向徘徊，气泡显示两行摘要和等待时间；完整内容在待办面板中阅读。

每条便签最多2000字。便签保存成功后才清空输入；存储失败会保留草稿。复制内容不会移除访客，只有标记「已交办」才让访客离开，本次运行中可撤销最近一次交办。应用重启后保留已保存便签的原始创建时间。

门外访客只出现在户外场景，不重复绘制到室内窗玻璃。即使桌面都显示房间，待办面板仍提供户外预览。

## 天气与昼夜

桌面、窗口、屏保和待办预览使用同一快照与绝对时间。天气默认「随机轮换」，每45分钟进入一个天气时段：晴天约65%、多云18%、雨10%、雪5%、雷雨2%；相邻时段可能延续。也可选择「手动固定」，指定晴、多云、雨、雪和雷雨。切回随机时仍保留原手动选择；昼夜可跟随本机时间，或选择白天、黄昏和夜晚。

天气不再受待办等待时长、运行中的Codex任务或等待确认状态影响。访客与便签等待时间照常显示。所有宿主按同一份绝对时间日历计算随机天气，不依赖各自启动时间；主应用离线时仍继续同步轮换，不增加天气计时器。

雷雨有暗云、密雨和间隔较长的局部像素闪电，无雷声或全屏闪白。减少动态效果时关闭闪电。天气不访问位置或联网天气服务。

## 多显示器、桌面和屏保

桌面背景与系统屏保分别保存每块显示器的房间/窗外选择。桌面默认各屏为房间；屏保默认主屏为房间、其他屏幕为窗外。显示器通过UUID识别，天气、昼夜及远景取景保持同步。

桌面背景位于图标下方并支持鼠标穿透，关闭背景后恢复原系统壁纸；此功能不改写系统壁纸文件。普通全屏隐藏控制栏，Esc返回应用窗口。桌面最高15fps，普通窗口和屏保目标30fps；不可见或熄屏时暂停动画。

真实屏保使用ScreenSaverView，只读主应用快照。主应用关闭窗口后继续留在菜单栏同步；完全退出后，屏保按心跳超时规则显示离线休息。电脑睡眠时不承诺本地任务继续执行。

## 离屏天气预览

`--render` 默认固定显示 `--weather` 指定的天气，适合比较画面；添加 `--random-weather` 可预览生产环境使用的同一随机天气日历。例如：

```sh
build/虚拟工位.app/Contents/MacOS/VirtualWorkplace \
  --render "$PWD/build/random-weather.png" --background outdoors --random-weather
```

示例便签的 `--note-age` 只影响等待时间，不改变天气。导出不修改个人便签、任务或场景设置。
